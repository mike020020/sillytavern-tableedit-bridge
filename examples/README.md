# 示例：状态块 → 期望结果

这些例子按工具包里 `tableEdit-bridge.js` 的 **demo_* 示例表**设计：把脚本原样贴上、协议条目按模板导入后，
把下面任一文件的内容**整段粘到聊天里发出去**（或作为 AI 回复内容），再点脚本按钮「同步最后一条状态」，
对照「期望结果」检查即可。表名/列名换成你自己的以后，这些用例依然可以当回归用例用。

> 表结构（见脚本里 `SCHEMA`）：
> - `demo_state`（示例状态表，单行）：row_id / 当前位置 current_location / 示例时间 example_time（YYYY-MM-DD HH:MM）/ 示例标记 example_flag（是·否）/ 示例计数 example_counter（项A=N,项B=N）
> - `demo_npc_state`（示例NPC状态表，定位键 npc_name）：npc_name / example_score（-100~100）/ example_tag（≤10 字）/ updated_at
> - `demo_npc_profile`（示例NPC档案表，定位键 name）：name / appearance / brief_intro / alias（缺列自动补「未知」）

| 文件 | 用例 | 期望结果 |
| --- | --- | --- |
| `01-单行表-插入首行.txt` | 单行表-插入首行 | 提示「已写入 1 项」；示例状态表新增 row_id=1 的行，四个字段分别写入「某地点 / 2026-01-01 12:00 / 否 / 项A=0,项B=0」。 |
| `02-单行表-按定位键更新.txt` | 单行表-按定位键更新 | 提示「已写入 1 项」；只有「示例时间」变成 2026-01-01 12:30，其它列不变（更新只写本轮真正变化的列）。 |
| `03-按名字-行不存在自动转插入.txt` | 按名字-行不存在自动转插入 | 提示「已写入 1 项」；示例NPC状态表里没有 NPC甲 时自动插入一行（名为 upsert 行为），已有该行则只更新这两列。 |
| `04-档案表-缺列自动补未知.txt` | 档案表-缺列自动补未知 | 提示里带「示例NPC档案表 缺少 人物简介、别称，已补「未知」」；新行的四列全部非空（缺的两列写「未知」），不会留下空白单元格。 |
| `05-错误示例-枚举非法.txt` | 错误示例-枚举非法 | 整块拒绝，提示「示例状态表.示例标记 只能写 是／否」；表格**没有任何变化**（这类错误不会写半条）。 |
| `06-错误示例-格式非法.txt` | 错误示例-格式非法 | 整块拒绝，提示「示例状态表.示例时间 格式必须是 YYYY-MM-DD HH:MM」。 |
| `07-错误示例-表名非法.txt` | 错误示例-表名非法 | 整块拒绝，提示「表不允许或表名不符合 DDL：示例状态表」——table 必须写物理表名（demo_state），不能写显示名/中文名/sheet_ 前缀。 |
| `08-宽容模式-越界列只丢弃.txt` | 宽容模式-越界列只丢弃 | 提示「已写入 1 项」+「示例状态表 没有可写列「updated_at」，已忽略该列」；时间照常写入，未知列只被丢弃（严格模式下改为整块拒绝）。 |
| `09-多标签-只取最后一对.txt` | 多标签-只取最后一对 | 正常写入：桥从后往前找第一个能解析成 JSON 的 <tableEdit>…</tableEdit> 对，思维链里游离的标签不影响。 |

## 怎么用这些例子排错

1. 先跑 01→02：确认**写入链路**通（能写、能更新、能去重——同一段再点一次应提示「这条状态已经同步过」）。
2. 再跑 03→04：确认**定位与补值**行为符合预期（upsert、缺列补「未知」）。
3. 最后跑 05→07：确认**校验**生效（枚举 / 格式 / 表名三类错误都整块拒绝，且表格没变化）。
4. 跑 08：确认**宽容模式**（未知列只丢弃并提示）；开了严格模式后同一条应变成整块拒绝。
5. 跑 09：确认**取块规则**（只认最后一对标签，思维链里的游离标签不影响）。

如果某一步与期望不符，先看提示文案，再对照 README「常见报错与处理」一节。
